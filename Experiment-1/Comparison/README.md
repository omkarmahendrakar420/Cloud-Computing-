# Hypervisor Performance Comparison

## Overview
This section presents the comparative analysis of CPU benchmark performance between a **Type-1 bare-metal hypervisor (Proxmox VE)** and a **Type-2 hosted hypervisor (VMware Workstation)**. 

Both environments were configured with identical resource specifications (Ubuntu 22.04+, 2 vCPUs, 2 GB RAM, 20 GB Disk) and evaluated using the Sysbench CPU workload (`--cpu-max-prime=20000`).
